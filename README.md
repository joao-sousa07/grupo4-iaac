# Grupo 4 - IAAC

Estrutura organizada do projeto, seguindo uma abordagem modular semelhante a projetos de Data Science, com separação entre dados, notebooks, código-fonte, modelos, documentação, relatórios e testes.

## Estrutura

- `data/` — dados brutos e processados
- `docs/` — documentação do projeto
- `models/` — modelos e resultados de treino
- `notebooks/` — análise e experimentação
- `references/` — referências e materiais de apoio
- `reports/` — relatórios e figuras
- `src/` — código principal do projeto
- `tests/` — testes

## Grupo 4

Projeto desenvolvido no âmbito da unidade curricular de IAAC.
